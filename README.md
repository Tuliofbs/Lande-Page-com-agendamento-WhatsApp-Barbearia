## 📖 Sobre o Projeto

A **Barbearia Elite** é uma aplicação web moderna voltada para o segmento de barbearias de alto padrão. O projeto oferece uma experiência imersiva e sofisticada para os clientes, permitindo conhecer diferenciais, serviços detalhados, profissionais qualificados, avaliações reais e realizar **agendamentos online rápidos com envio automático das informações direto para o WhatsApp** da barbearia.

## ✨ Funcionalidades Principais

- 📅 **Sistema de Agendamento em 4 Passos:** Seleção de serviço, profissional preferido, data (com carrossel dinâmico para o mês inteiro) e horários disponíveis.
- 💬 **Integração Inteligente com WhatsApp:** Montagem automática de mensagem formatada com todos os dados do agendamento para envio instantâneo.
- ⚡ **Experiência Fluida:** Interface altamente responsiva (Mobile e Desktop) com efeitos visuais e temas inspirados no universo vintage/luxo.
- 🏆 **Seção de Diferenciais:** Destaques para comodidades como cerveja gelada, profissionais premiados, ambiente climatizado e estacionamento.
- 📱 **Mobile First & Floating CTA:** Botões de ação rápida flutuantes para agendamento ágil em smartphones.

## 🚀 Como Executar o Projeto Localmente

Siga os passos abaixo para rodar o projeto em sua máquina:

### Pré-requisitos
Certifique-se de ter o **Node.js** instalado em seu computador.

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/barbearia-elite.git
   cd barbearia-elite
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Abra no navegador:**
   Acesse o endereço exibido no terminal (geralmente `http://localhost:3000`).
